# Buick Encore

A simple starter website for the Buick Encore project.

## Files included

- `index.html` — main page
- `style.css` — page styling
- `script.js` — interactive button behavior
- `package.json` — npm scripts and local development server
- `.gitignore` — ignore local files and dependencies

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the local development server:

   ```bash
   npm start
   ```

3. Open the site in your browser if it does not open automatically.
